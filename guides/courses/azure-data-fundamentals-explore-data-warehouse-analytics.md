# Введение в Microsoft Azure Data: аналитика в Azure

**Источник** https://learn.microsoft.com/en-us/training/paths/azure-data-fundamentals-explore-data-warehouse-analytics

## О курсе

Построение крупномасштабных решений аналитики данных: хранилища данных, потоковая обработка и визуализация.

- **Уровень:** начальный (Beginner)
- **Роль:** Data Analyst, Data Engineer, Database Administrator, Solution Architect, Student
- **Продукты и сервисы:** Azure, Microsoft Fabric, Power BI, Azure Databricks, Azure Data Factory, Azure Storage, Azure Event Hubs
- **Предварительные требования:** Основные концепции данных, реляционные и нереляционные данные.

## Чему научитесь

- Компоненты современных аналитических платформ и хранилищ данных.
- Основы потоковой обработки (stream processing) и сервисы Azure для нее.
- Основы аналитического моделирования данных и визуализации данных.

## Модули

1. **Компоненты современного хранилища данных**. Получить общее представление о компонентах крупномасштабного аналитического решения: архитектуре хранилища данных, процессах приема данных, аналитических хранилищах и сервисах Azure для их реализации. Модуль знакомит с Microsoft Fabric и Azure Databricks и включает практику в Microsoft Fabric. [guide](../modules/examine-components-of-modern-data-warehouse.md)
2. **Основы потоковой обработки данных в Azure**. Получить концептуальное представление о пакетной (batch) и потоковой (stream) обработке данных, о типовой архитектуре потоковых решений и о сервисах Azure и Microsoft Fabric для аналитики в реальном времени. Модуль не учит реализации потоковых решений. [guide](../modules/explore-fundamentals-stream-processing.md)
3. **Основы моделирования данных и визуализации в Power BI**. Изучить основные принципы аналитического моделирования данных и визуализации, используя Microsoft Power BI, и создать интерактивный отчет в Power BI Desktop. [guide](../modules/explore-fundamentals-data-visualization.md)

## Ключевые технологии и понятия

- Microsoft Fabric
- Azure Databricks
- ETL и ELT
- Data lakehouse
- Star schema и snowflake schema

- Direct Lake
- OneLake shortcut
- Mirroring
- OneLake
- Databricks SQL Warehouse
- Fabric Mirroring
- Eventstream
- Batch processing (пакетная обработка)

## Для каких ролей полезно

- Data Analyst (DA, аналитик данных)
- Data Engineer (DE, инженер данных)
- Database Administrator (администратор баз данных)
- Solution Architect (архитектор решений)
- Student (студент)
