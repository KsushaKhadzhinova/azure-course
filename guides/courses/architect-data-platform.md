# Проектирование платформы данных в Azure

**Источник** https://learn.microsoft.com/en-us/training/paths/architect-data-platform

## О курсе

Построение решений для хранения реляционных и NoSQL-данных в Azure, включая миграцию баз данных SQL Server.

- **Уровень:** средний (Intermediate)
- **Роль:** Solution Architect
- **Продукты и сервисы:** Azure, Azure SQL Database, Azure Synapse Analytics, Azure Cosmos DB
- **Предварительные требования:** Знакомство с реляционными и NoSQL-базами данных.

## Чему научитесь

- Инструменты миграции и перенос баз данных SQL Server в Azure SQL Database.
- Построение решений для хранения реляционных и NoSQL-данных в Azure.

## Модули

1. **Миграция SQL-нагрузок в Azure SQL Database**. Научиться планировать и выполнять миграцию баз данных SQL Server в Azure SQL Database: выбрать возможности целевой базы, выбрать офлайн- или онлайн-метод миграции (Azure Database Migration Service, BACPAC, транзакционная репликация, bcp, Azure Data Factory), контролировать производительность и подключения. [guide](../modules/migrate-sql-workloads-azure-sql-databases.md)

## Ключевые технологии и понятия

- Azure SQL Database
- Офлайн-миграция (offline)
- Онлайн-миграция (online)
- Azure Database Migration Service (DMS)
- BACPAC
- SqlPackage
- Transactional replication (транзакционная репликация)
- bcp
- Azure Data Factory
- Elastic query / elastic jobs
- Transient errors (временные ошибки)

## Для каких ролей полезно

- Solution Architect (архитектор решений)
