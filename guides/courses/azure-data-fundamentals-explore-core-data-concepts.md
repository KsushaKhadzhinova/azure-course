# Введение в Microsoft Azure Data: основные концепции данных

**Источник** https://learn.microsoft.com/en-us/training/paths/azure-data-fundamentals-explore-core-data-concepts

## О курсе

Основные концепции данных и роли специалистов по данным в решениях Microsoft Azure.

- **Уровень:** начальный (Beginner)
- **Роль:** Data Analyst, Data Engineer, Database Administrator, Developer, Solution Architect, Student
- **Продукты и сервисы:** Azure, Microsoft Fabric, Power BI, Azure Databricks, Microsoft Purview, Microsoft Foundry, Azure Data Factory, Azure Storage, Azure Cosmos DB, Azure SQL Database
- **Предварительные требования:** В источнике не указаны.

## Чему научитесь

- Роль данных в цифровой трансформации организаций.
- Роли специалистов по данным при создании и управлении программными решениями.

## Модули

1. **Основные концепции данных**. Освоить базовые понятия работы с данными: форматы данных (структурированные, полуструктурированные и неструктурированные), способы хранения в файлах и базах данных, а также характеристики транзакционной (OLTP) и аналитической (OLAP) обработки. Модуль закладывает основу для изучения сервисов Azure для работы с данными и является подготовкой к сертификации Azure Data Fundamentals. [guide](../modules/explore-core-data-concepts.md)
2. **Роли и обязанности специалистов по данным и сервисы Azure**. Познакомиться с ролями, которые организации назначают специалистам по данным, с их задачами и с сервисами Microsoft Azure, которые эти роли используют. [guide](../modules/explore-roles-responsibilities-world-of-data.md)

## Ключевые технологии и понятия

- Структурированные данные
- Полуструктурированные данные
- Неструктурированные данные
- BLOB (Binary Large Object)
- Реляционная БД
- Нереляционные БД (NoSQL)
- OLTP
- OLAP и semantic model
- Data lake, data warehouse, data lakehouse
- Medallion architecture
- JSON-документы клиентов
- CSV
- XML
- Database administrator (DBA)

## Для каких ролей полезно

- Data Analyst (DA, аналитик данных)
- Data Engineer (DE, инженер данных)
- Database Administrator (администратор баз данных)
- Developer (разработчик)
- Solution Architect (архитектор решений)
- Student (студент)
