# Определение и внедрение стратегии индексирования в Azure Cosmos DB для NoSQL

**Источник** https://learn.microsoft.com/en-us/training/paths/define-implement-indexing-strategy-cosmos-db-sql-api

## О курсе

Индексы и политики индексирования в Azure Cosmos DB for NoSQL и их настройка для контейнера.

- **Уровень:** средний (Intermediate)
- **Роль:** Developer
- **Продукты и сервисы:** Azure Cosmos DB
- **Предварительные требования:** Опыт создания облачных приложений на Microsoft C# или аналогичном языке программирования.

## Чему научитесь

- Индексы и политики индексирования в Azure Cosmos DB for NoSQL.
- Настройка политик индексирования для контейнера.

## Модули

1. **Определение индексов в Azure Cosmos DB для SQL API (NoSQL)**. Понять, как Azure Cosmos DB для NoSQL индексирует JSON-элементы по умолчанию, что такое индекс и политика индексирования, и какие типы путей и операторов используются при описании политики. [guide](../modules/define-indexes-azure-cosmos-db-sql-api.md)
2. **Настройка индексов в Azure Cosmos DB for NoSQL**. Научиться создавать пользовательскую политику индексирования (indexing policy) в Azure Cosmos DB for NoSQL и оценивать, подходит ли составной индекс (composite index) для решения. [guide](../modules/customize-indexes-azure-cosmos-db-sql-api.md)

## Ключевые технологии и понятия

- Индекс
- Indexing policy (политика индексирования)
- Indexing mode
- Automatic
- Included / excluded paths
- Операторы путей
- Range indexes
- Consistent
- None
- Indexing mode `consistent` / `automatic`
- includedPaths / excludedPaths
- Composite index (составной индекс)
- Ориентир порядка

## Для каких ролей полезно

- Developer (разработчик)
