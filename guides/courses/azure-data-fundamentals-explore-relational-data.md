# Введение в Microsoft Azure Data: реляционные данные в Azure

**Источник** https://learn.microsoft.com/en-us/training/paths/azure-data-fundamentals-explore-relational-data

## О курсе

Реляционные данные и сервисы Azure для реляционных баз данных: выбор, развертывание и миграция.

- **Уровень:** начальный (Beginner)
- **Роль:** Data Analyst, Data Engineer, Database Administrator, Developer, Solution Architect, Student
- **Продукты и сервисы:** Azure SQL Database
- **Предварительные требования:** В источнике не указаны.

## Чему научитесь

- Роль реляционных баз данных для транзакционных и аналитических данных.
- Выбор и развертывание сервисов Azure для реляционных баз данных.

## Модули

1. **Реляционные данные и предложения Azure**. Понять характеристики реляционных баз данных: как моделировать сущности в таблицах, зачем нужна нормализация, какие группы операторов SQL существуют и какие объекты базы данных (представления, хранимые процедуры, индексы) используются для организации и ускорения работы с данными. [guide](../modules/explore-relational-data-offerings.md)
2. **Реляционные СУБД в Azure: обзор и развертывание**. Изучить варианты реляционных сервисов баз данных в Azure (Azure SQL и сервисы для открытых СУБД MySQL и PostgreSQL), сравнить их по модели обслуживания, совместимости и сценариям использования и научиться развертывать сервис. [guide](../modules/explore-provision-deploy-relational-database-offerings-azure.md)

## Ключевые технологии и понятия

- Таблица (table)
- NULL
- Первичный ключ (primary key)
- Внешний ключ (foreign key)
- Составной ключ (composite key)
- Нормализация
- SQL и диалекты
- DDL, DCL, DML
- Представление (view), хранимая процедура (stored procedure), индекс (index)
- IaaS / PaaS
- SQL Server on Azure VMs
- Azure SQL Managed Instance
- Azure SQL Database
- Serverless compute tier

## Для каких ролей полезно

- Data Analyst (DA, аналитик данных)
- Data Engineer (DE, инженер данных)
- Database Administrator (администратор баз данных)
- Developer (разработчик)
- Solution Architect (архитектор решений)
- Student (студент)
