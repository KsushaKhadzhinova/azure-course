# Введение в Microsoft Azure Data (DP-900T00)

**Источник** https://learn.microsoft.com/en-us/training/courses/dp-900t00

## О курсе

Базовый курс по основным концепциям данных и сервисам данных Microsoft Azure; помогает подготовиться к сертификации Azure Data Fundamentals.

Люди, которые хотят изучить основы работы с базами данных в облаке и получить базовые знания облачных сервисов данных Azure.

- **Уровень:** начальный (Beginner)
- **Роль:** Data Engineer
- **Длительность:** 1 день
- **Продукты и сервисы:** Azure
- **Предварительные требования:** В источнике не указаны.

## Чему научитесь

- Основные концепции данных: реляционные, нереляционные данные, big data и аналитика.
- Реляционные данные и сервисы реляционных баз данных в Azure.
- Хранение нереляционных данных в Azure Storage и основы Azure Cosmos DB.
- Крупномасштабные хранилища данных, аналитика в реальном времени и визуализация данных.
