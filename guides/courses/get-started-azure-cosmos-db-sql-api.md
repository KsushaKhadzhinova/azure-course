# Начало работы с Azure Cosmos DB для NoSQL

**Источник** https://learn.microsoft.com/en-us/training/paths/get-started-azure-cosmos-db-sql-api

## О курсе

Знакомство с Azure Cosmos DB for NoSQL и создание первого аккаунта, базы данных и контейнера.

- **Уровень:** средний (Intermediate)
- **Роль:** Data Engineer, Developer
- **Продукты и сервисы:** Azure, Azure Cosmos DB
- **Предварительные требования:** Знакомство с Azure и порталом Azure; опыт программирования на C#. Без опыта программирования в источнике рекомендован вводный путь по основам программирования.

## Чему научитесь

- Что такое Azure Cosmos DB for NoSQL и подходит ли он вашему приложению.
- Создание аккаунта, базы данных и контейнера.

## Модули

1. **Введение в Azure Cosmos DB для NoSQL (SQL API)**. Оценить, подходит ли Azure Cosmos DB для NoSQL для вашего приложения, и понять, как его возможности отвечают на требования современных приложений. [guide](../modules/introduction-to-azure-cosmos-db-sql-api.md)
2. **Начало работы с Azure Cosmos DB for NoSQL**. Освоить базовую иерархию ресурсов аккаунта Azure Cosmos DB for NoSQL и научиться создавать аккаунт, базу данных, контейнер и элементы (items). [guide](../modules/try-azure-cosmos-db-sql-api.md)

## Ключевые технологии и понятия

- NoSQL (нереляционная БД)
- Документная модель (document data model)
- Azure Cosmos DB for NoSQL
- Аккаунт (account)
- База данных (database)
- Контейнер (container)
- Элемент (item)
- Ключ партиции (partition key path)
- Account (аккаунт)
- Database (база данных)
- Container (контейнер)
- Item (элемент)
- Stored procedures, triggers, UDF
- Partition key (ключ партиционирования)

## Для каких ролей полезно

- Data Engineer (DE, инженер данных)
- Developer (разработчик)
