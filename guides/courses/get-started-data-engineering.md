# Введение в инженерию данных в Azure

**Источник** https://learn.microsoft.com/en-us/training/paths/get-started-data-engineering

## О курсе

Роль инженера данных в Azure, основные операции с данными и Azure Data Lake Storage Gen2 как data lake.

- **Уровень:** средний (Intermediate)
- **Роль:** Data Engineer
- **Продукты и сервисы:** Azure Data Lake Storage
- **Предварительные требования:** В источнике рекомендовано предварительно получить сертификацию Microsoft Azure Data Fundamentals или эквивалентные знания и опыт.

## Чему научитесь

- Роль инженера данных: интеграция, трансформация и консолидация данных.
- Azure Data Lake Storage Gen2 как масштабируемое облачное хранилище для data lake.

## Модули

1. **Введение в инженерию данных в Azure**. Понять роль инженера данных (data engineer), основные операции с данными (интеграция, трансформация, консолидация), ключевые концепции (операционные и аналитические данные, потоковые данные, пайплайны, data lake, data warehouse, lakehouse, Apache Spark) и сервисы Azure, которые используются для этих задач. [guide](../modules/introduction-to-data-engineering-azure.md)
2. **Введение в Azure Data Lake Storage**. Понять назначение озера данных (data lake), возможности Azure Data Lake Storage Gen2 (безопасность, производительность, избыточность), отличия от Blob Storage, этапы обработки больших данных и типовые аналитические сценарии. [guide](../modules/introduction-to-azure-data-lake-storage.md)

## Ключевые технологии и понятия

- Data engineer (инженер данных)
- Структурированные данные
- Полуструктурированные данные
- Data integration (интеграция)
- ETL / ELT
- Data consolidation (консолидация)
- Operational vs analytical data
- Streaming data (потоковые данные)
- Data pipeline (пайплайн данных)
- Data lake (озеро данных)
- Data warehouse (хранилище данных)
- Lakehouse (лейкхаус)
- Apache Spark
- KQL (Kusto Query Language)

## Для каких ролей полезно

- Data Engineer (DE, инженер данных)
