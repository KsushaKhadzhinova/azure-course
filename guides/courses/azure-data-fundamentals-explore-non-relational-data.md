# Введение в Microsoft Azure Data: нереляционные данные в Azure

**Источник** https://learn.microsoft.com/en-us/training/paths/azure-data-fundamentals-explore-non-relational-data

## О курсе

Хранение и запросы нереляционных данных с помощью Azure Storage и Azure Cosmos DB.

- **Уровень:** начальный (Beginner)
- **Роль:** Data Analyst, Data Engineer, Database Administrator, Developer, Solution Architect, Student
- **Продукты и сервисы:** Azure Cosmos DB, Azure Table Storage, Azure Blob Storage, Azure Files
- **Предварительные требования:** В источнике не указаны.

## Чему научитесь

- Azure Storage как базовый сервис хранения нереляционных данных.
- Azure Cosmos DB как масштабируемое хранилище нереляционных данных.

## Модули

1. **Знакомство с нереляционными службами данных Azure: Storage и Data Lake**. Изучить базовые возможности Azure Storage и Microsoft OneLake для приложений с нереляционными (NoSQL) хранилищами: Blob Storage, Data Lake Storage Gen2, Azure Files и Azure Tables, а также научиться создавать и использовать учетную запись хранения (storage account). [guide](../modules/explore-provision-deploy-non-relational-data-services-azure.md)
2. **Нереляционные хранилища данных в Azure и Azure Cosmos DB**. Понять, чем нереляционные (NoSQL) хранилища отличаются от реляционных, описать ключевые возможности Azure Cosmos DB, выбрать один из пяти API Cosmos DB под существующие навыки и данные, а также знать, когда Cosmos DB подходит и когда нет. [guide](../modules/explore-non-relational-data-stores-azure.md)

## Ключевые технологии и понятия

- Blob storage (Blob Storage)
- Block / Page / Append blob
- Access tiers (уровни доступа)
- Lifecycle management policy
- Redundancy (избыточность)
- Azure Data Lake Storage Gen2
- Hierarchical namespace (иерархическое пространство имен)
- Microsoft OneLake
- Azure Files
- Azure Table Storage
- Azure Cosmos DB for Table
- NoSQL-базы данных
- Azure Cosmos DB
- Schema-agnostic (без жесткой схемы)

## Для каких ролей полезно

- Developer (разработчик)
