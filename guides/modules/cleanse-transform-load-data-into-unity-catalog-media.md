## Что запомнить

- Текст модуля в исходниках отсутствует, только изображения; сведения требуют проверки по оригинальной странице.
- Темы модуля по заголовкам: профилирование данных, сводная статистика через SQL, выбор типов данных, работа со сложными типами, пропуски, поиск и удаление дубликатов.
- Оригинальную страницу модуля нужно открыть в браузере, чтобы получить содержание.
- Гайд не дополняет сведения, которых нет в исходниках.
- Связанные модули смотрите в каталоге батча (например, `ingest-data-into-unity-catalog-media`).
