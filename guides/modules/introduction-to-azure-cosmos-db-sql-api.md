# Введение в Azure Cosmos DB для NoSQL (SQL API)

**Источник:** https://learn.microsoft.com/en-us/training/modules/introduction-to-azure-cosmos-db-sql-api/

## Цель модуля

Оценить, подходит ли Azure Cosmos DB для NoSQL для вашего приложения, и понять, как его возможности отвечают на требования современных приложений.

## Ключевые понятия

- **NoSQL (нереляционная БД)** - хранилище без жесткой схемы, которое масштабируется горизонтально за счет шардирования или партиционирования и не накладывает реляционных ограничений.
- **Документная модель (document data model)** - данные хранятся как самостоятельные документы, чаще всего в формате JSON; документ - атомарная единица записи.
- **Azure Cosmos DB for NoSQL** - быстрая NoSQL- и векторная база данных с глобальным распределением; поддерживает SDK для .NET, Java, Python, JavaScript и Go.
- **Аккаунт (account)** - единица высокой доступности и изоляции; задает регионы, DNS-имя и уровень консистентности по умолчанию.
- **База данных (database)** - логическая единица управления контейнерами.
- **Контейнер (container)** - основная единица масштабирования; здесь задаются throughput, индексная политика и TTL по умолчанию.
- **Элемент (item)** - JSON-документ внутри контейнера.
- **Ключ партиции (partition key path)** - путь в документе, по значению которого данные распределяются по партициям; обязателен для контейнера и один из важнейших выборов при проектировании.

## Содержание по урокам

### 1. Введение
URL: https://learn.microsoft.com/en-us/training/modules/introduction-to-azure-cosmos-db-sql-api/1-introduction

Современные приложения работают с данными в реальном времени, должны быть устойчивыми и гибкими, поддерживать ИИ. Сценарий модуля: ведущий разработчик розничной компании создает онлайн-витрину с ИИ-агентами, которая должна выдерживать всплески спроса при запуске и распродажах, работать с векторными данными для поиска.

### 2. Что такое Azure Cosmos DB для NoSQL
URL: https://learn.microsoft.com/en-us/training/modules/introduction-to-azure-cosmos-db-sql-api/2-what-azure-cosmos-db-sql-api

Объяснение NoSQL и документной модели: высокие объемы, разнородные источники, динамическая схема, высокая скорость данных. Azure Cosmos DB для NoSQL нативно поддерживает JSON, имеет векторную индексацию и поиск, языки запросов с синтаксисом, похожим на SQL для JSON. Перечислены преимущества: векторная база, скорость при любом масштабе, SDK для популярных языков, бизнес-непрерывность и SLA 99,999 %, полностью управляемый сервис с serverless-режимом и автоматическим масштабированием. Особенно подходит для нагрузок с непредсказуемыми всплесками, большим объемом данных, real-time и критичных к непрерывности.

### 3. Как работает Azure Cosmos DB для NoSQL
URL: https://learn.microsoft.com/en-us/training/modules/introduction-to-azure-cosmos-db-sql-api/3-how-does-work

Иерархия ресурсов: аккаунт - база данных - контейнер - элементы. Аккаунт задает регионы, DNS-имя и консистентность по умолчанию; throughput настраивается на уровне контейнера; контейнер может иметь индексную политику и TTL по умолчанию. Операции записи над JSON-документом атомарны. Ключ партиции (например, `/department/name`) определяет логическое разбиение; его выбор - одно из важнейших решений при проектировании нагрузки.

### 4. Когда использовать Azure Cosmos DB для NoSQL
URL: https://learn.microsoft.com/en-us/training/modules/introduction-to-azure-cosmos-db-sql-api/4-when-should-you-use

Гарантированные ответы в единицы миллисекунд (single-digit ms), доступность 99,999 %, векторные возможности, автоматическое мгновенное масштабирование, SLA по пропускной способности, консистентности, доступности и задержке. Типичные сценарии: генеративный ИИ (векторы хранятся рядом с данными, Change Feed обновляет векторы почти в реальном времени, история чатов служит семантическим кэшем), розничная торговля и маркетинг (эластичность в пиковые периоды, несколько аккаунтов для корзины, инвентаря и каталога, интеграция с Azure Search), web и мобильные приложения (гибкие схемы, один аккаунт с репликацией в несколько регионов). В сценарии модуля для уведомлений о доставке упомянуты Azure Synapse Link, Azure Functions и Azure Logic Apps.

## Что запомнить

- Azure Cosmos DB для NoSQL - документная NoSQL-база с JSON, векторным поиском и глобальным распределением.
- Иерархия: аккаунт, база данных, контейнер, элемент; throughput задается на уровне контейнера.
- Ключ партиции обязателен и определяет масштабирование, поэтому его выбор - ключевое решение.
- Сервис подходит для непредсказуемых всплесков нагрузки, больших объемов, real-time и критичных систем.
- Для генеративного ИИ удобно хранить векторы вместе с данными и использовать Change Feed для обновления индексов.
