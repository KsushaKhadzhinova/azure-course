# Инструкции (задание)

Исходные требования владельца репозитория к этой сборке материалов по Azure:

1. Зайти на страницу PDP (Growth Portal), пройти по всем ссылкам, касающимся Azure, и собрать информацию по всем курсам и всем ссылкам внутри курсов (и по ссылкам ссылок). Скачать всё в папку `azure-course`.
2. Использовать также чат Gemini «Azure конспект» (Canvas-конспекты и текст чата). Собрать всё по темам PDP.
3. Ходить не только по курсам, но и по официальной документации Azure; также по связанным курсам и ссылкам: https://learn.microsoft.com/en-us/training/support/mcp и https://learn.microsoft.com/ru-ru/training/browse/ .
4. Скачивать картинки и видео. Проверить, что всё работает и отображается.
5. Сделать отдельный документ по каждому курсу / технологии / модулю.
6. Написать, по каким ещё темам и инструментам Azure можно собрать информацию. Роли пользователя: DE / BA / BI / DA / AI / ML / DS / DevOps. Собрать: Fabric, Databricks, Power BI, Key Vault, Monitor и остальное из списка.
7. Отдельно собрать: какую базу данных Azure и когда использовать.
8. Собрать информацию с курсов, готовящих к сертификации по Azure.
9. Подробно разобрать Databricks.
10. Сделать отдельный документ со всеми ссылками (`LINKS.md`).
11. Использовать дешёвых агентов для рутинной работы.
12. Когда сбор закончен: удалить всё с ноутбука, оставить только в удалённом репозитории https://github.com/KsushaKhadzhinova/azure-course , залить туда эти инструкции, регулярно делать коммиты.

Инструменты сбора лежат в `tools/` (краулер Microsoft Learn, загрузчик медиа, генератор LINKS.md).
